# QRavate OpenAPI specification

[![CI](https://github.com/QRavate/openapi/actions/workflows/ci.yml/badge.svg)](https://github.com/QRavate/openapi/actions/workflows/ci.yml)
[![Sync](https://github.com/QRavate/openapi/actions/workflows/sync.yml/badge.svg)](https://github.com/QRavate/openapi/actions/workflows/sync.yml)

The [OpenAPI 3.1](https://spec.openapis.org/oas/v3.1.0) specification of the [QRavate](https://www.qravate.com) REST API: dynamic QR codes, destinations, redirect rules, scheduled changes, scan stats and webhooks.

- **File:** [`openapi.json`](openapi.json)
- **Base URL:** `https://www.qravate.com/api/v1`
- **Readable documentation:** [www.qravate.com/docs](https://www.qravate.com/docs)
- **Always-current copy:** `https://www.qravate.com/docs/openapi.json`

The descriptions in the specification are in French, like the QRavate service. Operation IDs, fields and enums are in English.

## Use it

- **Import it** into Postman, Insomnia, Bruno or Hoppscotch to try the API (raw URL: `https://raw.githubusercontent.com/QRavate/openapi/main/openapi.json`).
- **Generate a client** in your language, for example with [OpenAPI Generator](https://openapi-generator.tech):

  ```bash
  npx @openapitools/openapi-generator-cli generate -i openapi.json -g python -o qravate-client
  ```

- **Give it to an AI coding assistant** to write code against the API.

**Authentication:** a secret key in the `Authorization: Bearer sk_…` header. Create one in your QRavate account, under **API et webhooks** (Pro and Max plans). The API allows 120 requests per minute per key.

Prefer no code? Use the [n8n](https://github.com/QRavate/n8n-nodes-qravate), [Zapier](https://github.com/QRavate/zapier) or [Make](https://github.com/QRavate/make) integrations, or the [MCP server](https://github.com/QRavate/mcp) for AI assistants.

## How this repository stays current

The specification is generated by the QRavate service. After each production deployment, and every day as a fallback, the [sync workflow](.github/workflows/sync.yml) copies it from `https://www.qravate.com/docs/openapi.json`, validates it and opens a pull request listing what changed (version, operations, schemas, webhooks). The history of `openapi.json` is therefore the history of the API.

```bash
npm install
npm run sync       # copy the live specification into openapi.json
npm run validate   # validate it against OpenAPI 3.1
```

Questions about the API: support@qravate.com. Problems with the specification itself: [open an issue](https://github.com/QRavate/openapi/issues).
